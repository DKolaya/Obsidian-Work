# Sync Log Index

Morning-sync routine run summaries, organized by month folder then weekly file (named by that week's Monday date). Written automatically by the `morning-vault-sync` scheduled task (weekdays 8:15 AM). Each weekday's summary is also mirrored same-day into `02_Daily` and cleared the following morning — this index and its month folders are the permanent record.
